AndeStay Hostel

Guía de lanzamiento — dominio, sitio web y sistema de reservas

1. Qué vamos a lanzar

  1. Sitio web AndeStay Hostel (ya está publicado en Vercel).
  2. Dominio propio (ejemplo: andestayhostel.com) — lo compras tú.
  3. Sistema de reservas (QloApps).

2. Lista rápida — lo que necesito de ti

# Tarea ¿Quién?
1 Decidir y comprar el dominio Tú
2 Enviar acceso DNS o configurar DNS con la guía Tú + yo
3 Conectar dominio + reservas al sitio Yo

3. Paso 1 — Comprar el dominio (tú)

3.1 Elegir el nombre

  • Buenos ejemplos: andestayhostel.com, andestay.com (si está libre).
  • Evita nombres muy largos o difíciles de escribir / dictar por teléfono.

3.2 Dónde comprarlo (elige uno)

  • Cloudflare Registrar — recomendado, simple: cloudflare.com
  • Namecheap — namecheap.com
  • Google / Squarespace Domains
  • O el registrador que uses normalmente en Perú

3.3 Qué hacer al comprar

  1. Crea una cuenta en el registrador.
  2. Busca el dominio y cómpralo (mínimo 1 año).
  3. Activa renovación automática (para no perder el dominio).
  4. Guarda usuario y contraseña en un lugar seguro.
  5. No configures una “página en construcción” del registrador — el sitio real estará en Vercel.

3.4 Qué enviarme después de comprar

Por WhatsApp o email, manda:

  1. El dominio exacto (ej. andestayhostel.com)
  2. Dónde lo compraste (Cloudflare / Namecheap / otro)
  3. Una de estas opciones:

Opción A (más fácil para ti):
“Te doy acceso al DNS” (me agregas como usuario o pasas login temporal).

Opción B:
“Yo pongo los DNS” — te mando 2–3 líneas exactas para copiar (Paso 2).

4. Paso 2 — Conectar el dominio al sitio

El sitio vive en Vercel. Hay que apuntar el dominio hacia Vercel.

Si eliges Opción B (tú configuras DNS)
Te enviaré algo parecido a esto (los valores exactos salen de Vercel):

Dominio principal (sin www)

  • Tipo: A
  • Nombre / Host: @
  • Valor: el que indique Vercel (a menudo 76.76.21.21)

Para www

  • Tipo: CNAME
  • Nombre / Host: www
  • Valor: el que indique Vercel (a menudo cname.vercel-dns.com)

Namecheap — cómo se hace

  1. Entra a Namecheap → Domain List → tu dominio → Manage.
  2. Pestaña Advanced DNS.
  3. Borra registros viejos A/CNAME que apunten a otra web (si existen).
  4. Add New Record con lo que te mande.
  5. Guarda.
  6. Espera de 15 minutos a 48 horas (normalmente menos de 2 horas).
  7. Avísame: “DNS listo”.

Cloudflare — cómo se hace

  1. Entra a Cloudflare → selecciona el dominio.
  2. Menú DNS → Records.
  3. Añade los registros A / CNAME que te envíe.
  4. Proxy (nubecita): sigue la instrucción (a veces debe estar en DNS only / gris).
  5. Avísame cuando esté guardado.
