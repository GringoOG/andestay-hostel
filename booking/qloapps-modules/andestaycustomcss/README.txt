AndeStay Custom CSS 1.0.0

Purpose
-------
Improves the readability of the white text over the homepage hero image.

Installation
------------
1. In QloApps Back Office, open Modules and Services > Module Manager.
2. Choose Upload a module.
3. Upload the ZIP file and install the module.
4. Clear the QloApps cache and reload the homepage.

Removal
-------
Uninstall or disable "AndeStay Custom CSS" in Module Manager.
